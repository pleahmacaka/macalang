# Benchmarks

Cross-language algorithm benchmarks comparing **Maca** against C, Rust, Go,
JavaScript (Node), and Python. Maca is built through the `maca` CLI
(Maca → C → `cc -O2`), so it lands in C's ballpark — the "C-tier native"
claim — while staying far ahead of interpreted / JIT'd runtimes on call-bound
work.

## Kernels

Two families:

| kernel | what it stresses | workload |
|---|---|---|
| `fib` | tree recursion, call overhead | `fib(40)` |
| `tak` | Takeuchi, dense nested recursion | `tak(32,16,8)` |
| `ackermann` | deep non-primitive recursion | `ackermann(3,10)` |
| `sieve` | array writes, tight loops | primes ≤ 10⁷ |
| `mandel` | floating-point inner loop | 800×800, ≤1000 iters |
| `matmul` | O(n³) loops over arrays | 400×400 integer |

Every language computes the identical result (the harness verifies each against
a known value before timing).

## Run

```sh
cargo build --release -p maca-driver     # the maca CLI
maca run bench/run.maca                  # builds + times + verifies everything
maca run bench/run.maca --runs 9         # more samples per contender
maca run bench/run.maca --only mandel    # one kernel, while you work on it
maca run bench/run.maca --help
```

Needs a native `cc` (Maca and C link through it). `rustc`, `go`, `node`, and
`python3` add their columns when present. Results land in `results.md` and
`results.json`.

`results.json` is also the baseline: it is read before the run and written
after, so every full run also prints what moved since the last one. A `--only`
run compares just the kernel it measured and leaves both files alone — three
rows written over the file would delete the other five kernels' numbers.

## Layout

- `*.maca` — the Maca implementations (also run under `maca run`)
- `ref/*.{c,rs,go,js,py}` — the reference implementations, one per language
- `run.maca` — build + time + verify + compare + write the table, over
  `modules/bench` (the statistics, the file format and the comparison) and
  `modules/cli` (the arguments and the tables)
- `results.md`, `results.json` — latest results (regenerated by `run.maca`)

Times are median wall-clock of the compiled/loaded program (compiled languages
are built once, then timed) and depend on the host, so re-run locally for
numbers you can cite.
