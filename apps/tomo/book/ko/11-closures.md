# 클로저와 제어 흐름

## 함수는 값이다

이름으로 참조한 최상위 함수는 값입니다 — 함수를 기대하는 자리에 그대로
넘길 수 있습니다:

```maca
is_even(n: int) -> bool => n % 2 == 0
evens = [1, 2, 3, 4].filter(is_even)   // [2, 4]
```

람다는 주변 스코프를 캡처합니다:

```maca
step = 10
bumped = [1, 2, 3].map(n => n + step)  // [11, 12, 13]
```

주석이 없는 파라미터가 본문에서 *호출*되면 함수로 추론되므로, 고차 함수 코드에
특별한 문법이 필요 없습니다:

```maca
run_twice(f, x) => f(f(x))
run_twice(n => n + 1, 40)              // 42
```

람다는 반환 타입을 본문에서 추론하고, 직접 선언할 수도 있습니다.

```maca
inc = (n) -> int => n + 1
```

어노테이션을 쓸 때는 파라미터를 괄호로 묶으세요. 파라미터가 하나면 어느 쪽이든
되지만 둘이면 안 됩니다. `a, b -> int => …`는 목록이 어디서 끝나는지 말할 방법이
없으니까요. 어노테이션이 필요한 때는 컴파일러가 스스로 볼 수 없는 타입에 람다를
맞춰야 할 때입니다. 그런 경우는 한 군데뿐이고 레퍼런스에 있습니다. Rust trait
구현, [타깃](a10-targets.md)입니다.

람다 본문은 `match` 갈래와 마찬가지로 블록이 될 수 있습니다.

```maca
classify = (n) -> str => {
    doubled = n * 2
    doubled > 10 ? "big" : "small"
}
```

그래서 `=>` 뒤의 맨 `{ … }`는 익명 레코드가 아니라 그 블록입니다. 레코드를
뜻했다면 괄호로 감싸세요 — `(n) => ({ x = n })`.


## 식으로서의 `if`

제어 흐름은 값을 만듭니다. `if`/`else`는 식입니다:

```maca
label = if score >= 60 { "합격" } else { "불합격" }
```

흔한 두 갈래 선택에는 공백을 띄운 삼항 연산자가 있습니다:

```maca
label = score >= 60 ? "합격" : "불합격"
```

## `match`

`match`가 주력입니다. 합타입, 리터럴, 리스트에 모두 동작하며 빠짐없이 다뤄야
합니다:

```maca
describe(xs: int[]) -> str =>
    match xs {
        []          => "비어 있음"
        [x]         => "하나: {x}"
        [x, ..rest] => "머리 {x}, 이어서 {rest.length()}개 더"
    }
```

대괄호는 선택입니다 — Maca의 대괄호 없는 콤마 리스트와 결을 맞춰 `x, ..rest`도
똑같이 매칭됩니다. 읽기 좋은 쪽을 쓰세요. 대괄호는 비어 있음과 원소 하나인
경우를 더 분명하게 드러냅니다.

## 반복

`while`과 `for`는 문입니다. `for`는 리스트를 순회하거나, `..`로 쓴 정수 범위를
(양 끝 포함) 순회합니다.

```maca
sum_to(n: int) -> int {
    total = 0
    for i in 1..n {          // 1, 2, …, n
        total = total + i
    }
    total
}
```

`while`은 조건을 받고, 카운터는 직접 움직입니다.

```maca
countdown(start: int) -> int {
    n = start
    while n > 0 {
        info("{n}")
        n = n - 1
    }
    0
}
```

`break`와 `continue`는 예상대로 동작합니다. Maca의 관용구는 명시적 반복문보다
재귀와 리스트 메서드(`map`/`filter`/`reduce`)에 기웁니다 — 대개 더 짧고 의도가
그대로 드러나기 때문입니다.

## 오류 전파

실패할 수 있는 호출은 호출 지점에 `?`를 붙여 표시합니다. 실패하면 곧바로
반환하고, 성공하면 값을 꺼냅니다:

```maca
config = read_file("app.toml")?      // 실패를 호출자에게 전파
```
