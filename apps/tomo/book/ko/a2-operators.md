# 연산자와 기호

모든 연산자와 그 뜻, 그리고 결합 순서. 어휘 규칙은 [문법](a5-syntax.md)에
있습니다.

## 산술

| 연산자 | 의미 |
|---|---|
| `+` `-` `*` `/` | `int`와 `float`에 대해, 통상적인 것 |
| `%` | 나머지 |
| `-x` | 부호 반전 |

## 비교와 논리

| 연산자 | 의미 |
|---|---|
| `==` `!=` | 같음. 문자열에도 동작 |
| `<` `>` `<=` `>=` | 순서 |
| `&&` `\|\|` | 불리언 and/or |
| `!x` | 부정 |

긴 조건은 연산자를 앞 줄 끝에 두든 다음 줄 맨 앞에 두든 하나의 식으로 읽힙니다.

```maca
ok = a > 0 &&
    b > 0

fine = a > 0
    && b > 0
```

줄을 *시작할* 수 있는 것은 `&&`, `||`, `++`, `.`, `?`, `:` 여섯입니다. `-`가
함정입니다. 식을 시작할 수 있으므로 줄 앞의 `-`는 위 줄을 이어가는 대신 새
문장을 시작하고, 아무 경고도 없습니다.

## 비트

| 연산자 | 의미 |
|---|---|
| `<<` `>>` | 시프트 |

## 이어붙이기

| 연산자 | 의미 |
|---|---|
| `++` | 문자열 둘 또는 리스트 둘을 이음 |

`+`는 이어붙이지 않습니다.

## 제어

| 형태 | 의미 |
|---|---|
| `c ? x : y` | 삼항. **띄어서** 씀 |
| `x?` | 실패 전파. **붙여서** 씀 |
| `lo..hi` | 반열린 범위. `hi`는 빠집니다 |
| `x, ..rest` | `match`의 나머지 패턴 |

띄어쓰기 대 붙여쓰기의 구분은 언어에 세 번 등장합니다. 띄어 쓴 `?`는 삼항이고
붙여 쓴 `?`는 에러 전파, 띄어 쓴 `:`는 삼항의 뒷부분이고 보간 안의 붙여 쓴
`:`는 포맷 스펙, 띄어 쓴 `-`는 빼기지만 붙여 쓴 `-`는 이름의 일부입니다.

## 접근

| 형태 | 의미 |
|---|---|
| `r.f` | 필드 |
| `xs[i]` | 인덱스. 대입도 가능 |
| `x.f(y)` | UFCS: `f(x, y)`와 같음 |
| `r with { f = v }` | 함수형 갱신 |

## 문자열 안에서

| 형태 | 의미 |
|---|---|
| `{expr}` | 보간 |
| `{expr:spec}` | 포맷 스펙이 붙은 보간 |
| `\{` `\}` 또는 `{{` `}}` | 리터럴 중괄호 |
| `\n` `\t` `\r` `\0` `\\` `\"` | 이스케이프 |
| `"""…"""` | raw. 여러 줄, 보간 없음 |

### 포맷 스펙

`[정렬][0][너비][.정밀도]`이고 각 부분은 모두 선택입니다.

| 스펙 | `3.14159` / `42` / `"ok"`에 대해 | 결과 |
|---|---|---|
| `{x:.2}` | `3.14159` | `3.14` |
| `{x:>8}` | `42` | `      42` |
| `{x:<8}` | `"ok"` | `ok      ` |
| `{x:^8}` | `"ok"` | `   ok   ` |
| `{x:08}` | `42` | `00000042` |
| `{x:>10.3}` | `3.14159` | `     3.142` |

`{x:.2}`는 `x.fixed(2)`이고 `{x:>8}`은 `str(x).pad_start(8, " ")`입니다.

## 선언

| 형태 | 의미 |
|---|---|
| `Name = { f: T }` | 레코드 타입 |
| `Name = A \| B(int)` | 합타입 |
| `f(a: T) -> R { … }` | 함수, 블록 본문 |
| `f(a: T) -> R => e` | 함수, 화살표 본문 |
| `v => e` | 람다 |
| `alias N = T` | 타입 별칭 |

## 수 리터럴

| 형태 | 값 |
|---|---|
| `42` | 10진 |
| `0xff` `0b1010` `0o755` | 16진, 2진, 8진 |
| `1_000_000` | `_` 구분자는 무시됨 |
| `3.14` | 실수 |

## 우선순위, 느슨한 것부터

1. `? :` (삼항)
2. `\|\|`
3. `&&`
4. `==` `!=` `<` `>` `<=` `>=`
5. `++`
6. `<<` `>>`
7. `+` `-`
8. `*` `/` `%`
9. 단항 `-` `!` `await` `spawn`
10. 호출, 인덱스, 필드, UFCS

`await a + await b`는 `(await a) + (await b)`입니다.
