# 부록 B: 연산자와 기호

## 산술

| 연산자 | 의미 |
|---|---|
| `+` `-` `*` `/` | `int`와 `float`에 대해, 통상적인 것 |
| `%` | 나머지 |
| `-x` | 부호 반전 |

## 비교와 논리

| 연산자 | 의미 |
|---|---|
| `==` `!=` | 같음. 문자열에도 동작 |
| `<` `>` `<=` `>=` | 순서 |
| `&&` `\|\|` | 불리언 and/or |
| `!x` | 부정 |

줄이 `&&`나 `||`로 **시작**할 수는 없습니다. 렉서가 개행을 구분자로 취급하기
때문입니다. 연산자를 앞 줄 끝에 두세요.

```maca
ok = a > 0 &&
    b > 0
```

## 비트

| 연산자 | 의미 |
|---|---|
| `<<` `>>` | 시프트 |

## 이어붙이기

| 연산자 | 의미 |
|---|---|
| `++` | 문자열 둘 또는 리스트 둘을 이음 |

`+`는 이어붙이지 않습니다. `++`가 별도의 연산자인 것은 정확히 `"1" ++ "2"`와
`1 + 2`가 절대 헷갈리지 않게 하기 위해서입니다.

## 제어

| 형태 | 의미 |
|---|---|
| `c ? x : y` | 삼항. **띄어서** 씀 |
| `x?` | 실패 전파. **붙여서** 씀 |
| `lo..hi` | 양끝 포함 범위 |
| `x, ..rest` | `match`의 나머지 패턴 |

띄어쓰기 대 붙여쓰기의 구분은 실제로 일을 하고, 언어에 세 번 등장합니다. 띄어 쓴
`:`는 삼항이고, 보간 안에서 붙여 쓴 `:`는 포맷 스펙입니다. 띄어 쓴 `?`는
삼항이고, 붙여 쓴 `?`는 에러 전파입니다.

## 접근

| 형태 | 의미 |
|---|---|
| `r.f` | 필드 |
| `xs[i]` | 인덱스. 대입도 가능 |
| `x.f(y)` | UFCS — `f(x, y)`와 같음 |
| `r with { f = v }` | 함수형 갱신 |

## 문자열 안에서

| 형태 | 의미 |
|---|---|
| `{expr}` | 보간 |
| `{expr:spec}` | 포맷 스펙이 붙은 보간 |
| `\{` `\}` 또는 `{{` `}}` | 리터럴 중괄호 |
| `\n` `\t` `\r` `\0` `\\` `\"` | 이스케이프 |
| `"""…"""` | raw. 여러 줄, 보간 없음 |

### 포맷 스펙

`[정렬][0][너비][.정밀도]`이고 각 부분은 모두 선택입니다.

| 스펙 | `3.14159` / `42` / `"ok"`에 대해 | 결과 |
|---|---|---|
| `{x:.2}` | `3.14159` | `3.14` |
| `{x:>8}` | `42` | `      42` |
| `{x:<8}` | `"ok"` | `ok      ` |
| `{x:^8}` | `"ok"` | `   ok   ` |
| `{x:08}` | `42` | `00000042` |
| `{x:>10.3}` | `3.14159` | `     3.142` |

스펙은 문법 설탕입니다. `{x:.2}`는 `x.fixed(2)`이고 `{x:>8}`은
`str(x).pad_start(8, " ")`이므로, 모든 백엔드가 똑같이 지원합니다.

## 선언

| 형태 | 의미 |
|---|---|
| `Name = { f: T }` | 레코드 타입 |
| `Name = A \| B(int)` | 합타입 |
| `f(a: T) -> R { … }` | 함수, 블록 본문 |
| `f(a: T) -> R => e` | 함수, 화살표 본문 |
| `v => e` | 람다 |
| `alias N = T` | 타입 별칭 |

## 수 리터럴

| 형태 | 값 |
|---|---|
| `42` | 10진 |
| `0xff` `0b1010` `0o755` | 16진, 2진, 8진 |
| `1_000_000` | `_` 구분자는 무시됨 |
| `3.14` | 실수 |

## 우선순위, 느슨한 것부터

1. `? :` (삼항)
2. `\|\|`
3. `&&`
4. `==` `!=` `<` `>` `<=` `>=`
5. `++`
6. `<<` `>>`
7. `+` `-`
8. `*` `/` `%`
9. 단항 `-` `!` `await` `spawn`
10. 호출, 인덱스, 필드, UFCS

`await`와 `spawn`이 단항 우선순위로 묶이므로 `await a + await b`는
`(await a) + (await b)`입니다. 원하는 결과죠.
