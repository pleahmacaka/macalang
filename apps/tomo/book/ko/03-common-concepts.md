# 기본 개념

타입을 직접 쓰는 곳은 함수 경계 정도이고 나머지는 컴파일러가 추론합니다.

## 스칼라

- `int`: 64비트 정수. `42`, `-7`, `0xff`, `1_000_000`.
- `float`: 64비트 실수. `3.14`, `2.0`.
- `bool`: `true` 또는 `false`.
- `str`: 문자열. `"hello"`, 그리고 보간을 하는 `"n = {n}"`.

## 문자열

`"…"` 안의 `{expr}`는 평가되어 그 자리에 들어갑니다. 글자 그대로의 중괄호는 두
번 겹치거나 백슬래시로 이스케이프합니다.

```maca
info("n = {n}")        // n을 보간
info("{{}}")           // {} 출력
info("\{\}")           // 같은 결과, 이스케이프 표기
```

틀리면 컴파일 에러가 납니다.

### 포맷 스펙

보간은 `:` 뒤에 값을 어떻게 렌더링할지 지정할 수 있습니다.

```maca
info("{pi:.2}")        // 3.14        (소수점 두 자리)
info("{n:>8}")         // "      42"  (8칸에 오른쪽 정렬)
info("{name:<8}")      // "ok      "  (왼쪽 정렬)
info("{name:^8}")      // "   ok   "  (가운데 정렬)
info("{n:08}")         // "00000042"  (0으로 채우기)
info("{pi:>10.3}")     // "     3.142" (둘 다)
```

스펙은 `[정렬][0][너비][.정밀도]`이고 각 부분은 모두 선택입니다.
`{x:.2}`는 `x.fixed(2)`, `{x:>8}`은 `str(x).pad_start(8, " ")`입니다.

삼항은 **띄어서**(`c ? x : y`), 포맷 스펙은 **붙여서**(`x:>8`) 쓰므로 보간 안의
삼항도 그대로 됩니다.

```maca
info("{score >= 60 ? "pass" : "fail"}")
```

`"…"` 문자열은 한 줄을 넘지 않습니다. 여러 줄 텍스트에는 보간을 하지 않는
**raw** 문자열을 쓰세요.

```maca
css = """
body { margin: 0 }
"""
```

## 바인딩: 가변 vs 상수

소문자 이름은 **가변** 변수를 바인딩합니다.

```maca
count = 0
count = count + 1   // OK
```

`const`, `as const`, 또는 **대문자로 시작하는** 이름은 **상수**입니다.

```maca
const Limit = 100
Limit = 200         // 에러: 상수를 재할당할 수 없음
```

`let`은 없습니다. 이름을 도입하는 것과 갱신하는 것 모두 같은 `=`를 씁니다.

## 레코드

레코드는 이름 붙은 필드를 묶습니다.

```maca
Point = {
    x: int
    y: int
}

p = Point { x = 3, y = 4 }
info("x는 {p.x}")            // `.`로 필드 접근
q = p with { y = 5 }         // 함수형 갱신(p는 그대로)
```

## 합타입

합타입은 여러 variant 중 하나이고, `match`가 이를 분해합니다.

```maca
Shape = Circle | Square | Triangle

sides(s: Shape) -> int =>
    match s {
        Circle   => 0
        Square   => 4
        Triangle => 3
    }
```

`match`는 빠짐없이 다뤄야 하고, variant를 빠뜨리면 컴파일러가 알려줍니다.

## 리스트

리스트는 한 타입의 값을 여럿 담고, stdlib 메서드는 UFCS라서 `.`로 호출합니다.

```maca
xs = [10, 20, 30]
info("첫값 {xs.first()}, 길이 {xs.length()}")
doubled = xs.map(n => n * 2)          // [20, 40, 60]
big     = xs.filter(n => n > 15)      // [20, 30]
total   = xs.reduce(0, (a, b) => a + b)
```

`n => n * 2`는 **람다**입니다([클로저와 제어 흐름](11-closures.md)).

## 타입 주석은 추론 힌트

함수의 파라미터와 반환에 주석을 달면 본문 안에서는 타입이 알아서 흐릅니다.
Maca가 알 수 없는 것을 만나면 프로그램을 거부하는 대신 점진적 `any`로
물러섭니다.
