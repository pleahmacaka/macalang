# 값과 타입

Maca는 정적 타입 언어지만, 타입을 직접 쓰는 곳은 함수 경계 정도이고 나머지는
컴파일러가 추론합니다.

## 스칼라

- `int` — 64비트 정수: `42`, `-7`, `0xff`, `1_000_000`.
- `float` — 64비트 실수: `3.14`, `2.0`.
- `bool` — `true` 또는 `false`.
- `str` — 문자열: `"hello"`, 보간 지원: `"n = {n}"`.

## 문자열

`"…"` 문자열은 보간을 합니다. 안에 있는 `{expr}`는 평가되어 그 자리에 들어갑니다.
그래서 중괄호는 특별한 문자이고, **글자 그대로의** 중괄호는 두 번 겹치거나
백슬래시로 이스케이프합니다:

```
info("n = {n}")        // n을 보간
info("{{}}")           // {} 출력
info("\{\}")           // 같은 결과, 이스케이프 표기
```

이걸 틀리면 조용히 넘어가지 않고 컴파일 에러가 납니다. `"{"`는 닫는 따옴표가
끝내주지 못하는 보간을 여는 셈이라, 컴파일러가 그렇게 알려줍니다.

### 포맷 스펙

보간은 `:` 뒤에 값을 어떻게 렌더링할지 지정할 수 있습니다.

```
info("{pi:.2}")        // 3.14        — 소수점 두 자리
info("{n:>8}")         // "      42"  — 8칸에 오른쪽 정렬
info("{name:<8}")      // "ok      "  — 왼쪽 정렬
info("{name:^8}")      // "   ok   "  — 가운데 정렬
info("{n:08}")         // "00000042"  — 0으로 채우기
info("{pi:>10.3}")     // "     3.142" — 둘 다
```

스펙은 `[정렬][0][너비][.정밀도]`이고 각 부분은 모두 선택입니다. 런타임에
새로 생기는 동작은 없습니다. 스펙은 직접 쓸 수도 있는 호출의 표기일 뿐이라
(`{x:.2}`는 `x.fixed(2)`, `{x:>8}`은 `str(x).pad_start(8, " ")`), 모든
타깃에서 똑같이 동작합니다.

보간 안의 삼항 연산자도 그대로 됩니다. Maca는 삼항을 **띄어서**(`c ? x : y`),
포맷 스펙을 **붙여서**(`x:>8`) 쓰기 때문입니다 — `x?`와 `c ? x : y`를 가르는
것과 같은 규칙입니다:

```
info("{score >= 60 ? "pass" : "fail"}")
```

`"…"` 문자열은 한 줄을 넘지 않습니다 — 줄바꿈은 `\n`으로 씁니다. 정말로 여러
줄인 텍스트에는 **raw** 문자열을 쓰세요. 여러 줄에 걸치고 보간을 하지 않으므로
안에 있는 중괄호도 이스케이프할 필요가 없습니다:

```
css = """
body { margin: 0 }
"""
```

## 바인딩: 가변 vs 상수

소문자 이름은 **가변** 변수를 바인딩합니다:

```
count = 0
count = count + 1   // OK
```

`const`, `as const`, 또는 **대문자로 시작하는** 이름은 **상수**를 바인딩합니다.
재할당하면 컴파일 에러입니다:

```
const Limit = 100
Limit = 200         // 에러: 상수를 재할당할 수 없음
```

`let`은 없습니다. 이름을 도입하는 것과 갱신하는 것 모두 같은 `=`를 씁니다.

## 레코드

레코드는 이름 붙은 필드를 묶습니다. 타입 선언과 값 생성:

```
Point = {
    x: int
    y: int
}

p = Point { x = 3, y = 4 }
info("x는 {p.x}")            // `.`로 필드 접근
q = p with { y = 5 }         // 함수형 갱신 — p는 그대로
```

## 합타입

합타입은 여러 variant 중 하나입니다. `match`가 이를 분해합니다:

```
Shape = Circle | Square | Triangle

sides(s: Shape) -> int =>
    match s {
        Circle   => 0
        Square   => 4
        Triangle => 3
    }
```

값은 반드시 정확히 하나의 variant이므로 `match`는 빠짐없이 다뤄야 합니다 —
variant를 빠뜨리면 컴파일러가 알려줍니다.

## 리스트

리스트는 한 타입의 값을 여럿 담습니다. stdlib 메서드는 UFCS라서 `.`로
호출합니다:

```
xs = [10, 20, 30]
info("첫값 {xs.first()}, 길이 {xs.length()}")
doubled = xs.map(n => n * 2)          // [20, 40, 60]
big     = xs.filter(n => n > 15)      // [20, 30]
total   = xs.reduce(0, (a, b) => a + b)
```

## 타입 주석은 추론 힌트

함수의 파라미터와 반환에는 주석을 답니다. 본문 안에서는 타입이 알아서
흐릅니다. Maca가 알 수 없는 것 — 알 수 없는 stdlib 값, 외부 호출 — 을 만나면
프로그램을 거부하는 대신 점진적 `any`로 물러섭니다. 덕분에 상호운용은 매끄럽게,
내 코드는 엄격하게 유지됩니다.
