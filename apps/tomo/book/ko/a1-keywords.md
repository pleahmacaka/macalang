# 부록 A: 키워드

Maca가 예약하는 단어는 21개입니다. 이것이 목록 전부입니다. 머릿속에 담을 수
있는 언어는 우연이 아니라 설계 목표입니다.

| 키워드 | 용도 |
|---|---|
| `const` | 상수 바인딩 선언 |
| `as` | `x = e as const`, 뒤에 붙는 상수 표시 |
| `if` | 조건. 식이기도 함 |
| `else` | 반대쪽 갈래 |
| `for` | 순회: `for x in xs { … }` |
| `in` | `for`의 구분자 |
| `while` | 조건이 참인 동안 반복 |
| `break` | 가장 안쪽 루프 탈출 |
| `continue` | 다음 반복으로 |
| `match` | 분해와 분기 |
| `import` | 모듈 또는 외부 라이브러리 들여오기 |
| `with` | 레코드 함수형 갱신: `p with { y = 5 }` |
| `fail` | 에러 발생 |
| `try` | 에러 잡기 |
| `alias` | 타입의 다른 이름 |
| `await` | `Future` 기다리기 |
| `spawn` | 동시 작업 시작 |
| `true` | 불리언 |
| `false` | 불리언 |

`from`은 이 목록에 *없습니다*. 선택적 import에 나오지만 거기서만이고, 나머지
자리에서는 평범한 식별자입니다. `copy(from, to)`는 키워드 하나를 쓰기엔 너무
자연스러운 매개변수 이름이니까요.

## Maca가 예약하지 **않는** 단어

다른 언어에서 손이 가는 단어들입니다. 어느 것도 키워드가 아니고, 식별자로 쓰는
것은 합법입니다. 다만 키워드*처럼* 쓰면 컴파일러가 Maca는 대신 무엇을 하는지
알려 줍니다.

| 키워드가 아닌 것 | Maca가 하는 것 |
|---|---|
| `fn`, `func`, `def` | 함수는 `name(a: T) -> R { … }` 또는 `=> e` |
| `let`, `var` | `x = e`가 바인딩, `const x = e`가 상수 |
| `return` | 함수의 마지막 식이 곧 값 |
| `type`, `struct`, `enum`, `class` | `Name = { f: T }` 또는 `Name = A \| B` |
| `async` | async는 추론되는 이펙트. `spawn`과 `await`를 쓸 것 |
| `null`, `nil`, `None` | null이 없음. 합타입을 쓸 것 |
| `pub`, `private` | 모듈이 정의한 모든 것이 import 가능 |
| `mut`, `&`, `move` | borrow checker가 없음 (4장) |
| `impl`, `trait`, `self` | 자유 함수 + UFCS가 곧 메서드 |
| `new` | 레코드 리터럴은 `Name { f = v }` |

예약되지 않았으므로 `type`이라는 변수나 `new`라는 함수도 컴파일됩니다. C 백엔드가
C 키워드와 충돌하는 이름을 맹글링하므로 `double`, `class`, `switch`도 Maca
식별자로 쓸 수 있습니다.

## 문맥적 문장부호

키워드는 아니지만 의미를 지니므로 여기 적어 둡니다.

| 토큰 | 의미 |
|---|---|
| `:` | **타입**을 도입 |
| `=` | **값**을 도입 |
| `=>` | 화살표 함수 본문 또는 `match` 갈래 |
| `->` | 반환 타입 |
| `?` `:` | 삼항. **띄어서** 씀 |
| `?` | 식에 **붙여서**: 실패 전파 |
| `..` | 양끝 포함 범위 또는 나머지 패턴 |
| `\|` | 합타입 변형 구분 |
| `_` | 와일드카드 패턴 |
