# 안녕, 세계

모든 Maca 프로그램은 `main`에서 시작하며, `main`은 `int` — 프로세스 종료 코드 —
를 반환합니다. 전체는 이렇습니다:

```
main() -> int {
    info("Hello, World")
    0
}
```

`hello.maca`로 저장하고 실행합니다:

```
maca run hello.maca
```

`Hello, World`가 출력되고, 프로세스는 코드 `0`으로 종료됩니다.

## 각 부분의 의미

`main() -> int`는 인자를 받지 않고 `int`를 반환하는 `main`이라는 함수를
선언합니다. `fn` 키워드는 없습니다. 이름과 매개변수 목록, 그리고 `-> 타입`이
함수 정의의 전부입니다.

중괄호 안은 **블록**이고, 블록의 값은 마지막 식입니다. 여기서는 `0`이고, 그것이
`main`이 반환하는 값입니다. `main`의 반환값이 프로세스 종료 상태이므로 `0`은
성공을 뜻합니다. 실패를 알리려면 다른 값을 반환하세요.

`info`는 한 줄을 출력합니다. syslog 레벨에서 이름을 딴 작은 가족의 하나이고,
`warn` 이하는 표준 에러로 나갑니다.

## 화살표 본문

본문이 하나의 식인 함수는 중괄호를 생략하고 `=>`를 쓸 수 있습니다:

```
double(n: int) -> int => n * 2
```

이는 `double(n: int) -> int { n * 2 }`와 정확히 같습니다. 더 읽기 좋은 쪽을
쓰세요.

## 실행 대신 빌드

`maca run`은 컴파일과 실행을 한 번에 합니다. 독립 실행 바이너리를 만들려면:

```
maca build hello.maca -o hello
./hello
```
