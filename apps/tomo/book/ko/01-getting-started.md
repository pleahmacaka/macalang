# 안녕, 세계

모든 Maca 프로그램은 `main`에서 시작하며, `main`은 `int` — 프로세스 종료 코드 —
를 반환합니다. 전체는 이렇습니다:

```
main() -> int {
    info("Hello, World")
    0
}
```

`hello.maca`로 저장하고 실행합니다:

```
maca run hello.maca
```

`Hello, World`가 출력되고, 프로세스는 코드 `0`으로 종료됩니다.

## 각 조각의 의미

- `main() -> int`는 인자가 없고 `int`를 반환하는 `main` 함수를 선언합니다.
  `fn` 키워드는 없습니다 — 이름 뒤에 `(...)`와 `-> Type`가 오면 함수입니다.
- `{ ... }`는 본문, 즉 **블록**입니다. 블록의 마지막 식이 그 값입니다. 여기서는
  블록의 값이 `0`이므로 `main`이 그것을 반환합니다.
- `info("Hello, World")`는 한 줄을 출력하는 `info` 빌트인을 호출합니다.
- `0`은 종료 코드입니다. 실패를 알리려면 0이 아닌 값을 반환하세요.

## 화살표 본문

본문이 하나의 식인 함수는 중괄호를 생략하고 `=>`를 쓸 수 있습니다:

```
double(n: int) -> int => n * 2
```

이는 `double(n: int) -> int { n * 2 }`와 정확히 같습니다. 더 읽기 좋은 쪽을
쓰세요.

## 실행 대신 빌드

`maca run`은 컴파일과 실행을 한 번에 합니다. 독립 실행 바이너리를 만들려면:

```
maca build hello.maca -o hello
./hello
```
