# 문법

언어가 가진 모든 형태를 한자리에 모았습니다. 무엇을 쓸지는 알고 정확한 표기가
필요할 때 펼치는 장입니다. 설명은 [Maca 배우기](03-common-concepts.md)에
있습니다.

전체를 관통하는 규칙이 둘 있고, 먼저 읽어 둘 값이 있습니다.

- **`:`는 타입을 도입하고 `=`는 값을 도입합니다.** 선언, 리터럴, 매개변수,
  바인딩이 모두 이 규칙을 따릅니다.
- **붙여 쓰기와 띄어 쓰기는 다른 뜻입니다.** `x?`는 실패를 전파하고
  `c ? x : y`는 삼항이며, `{n:>8}`은 포맷 스펙이고 `{c ? a : b}`는 문자열 안의
  삼항이고, `data-id`는 식별자 하나이고 `a - b`는 뺄셈입니다.

## 파일

파일 하나가 모듈 하나입니다. 최상위에는 import, 타입 선언, 상수, 함수가 순서에
상관없이 놓일 수 있습니다. 선언하는 줄보다 먼저 쓰여도 됩니다.

```maca
import std/text

Limit = 100

Point = {
    x: int
    y: int
}

main() -> int {
    info("{Limit}")
    0
}
```

엔트리 파일도, `package` 줄도, `mod` 블록도 없습니다.

## 주석

| 형태 | 의미 |
|---|---|
| `// 텍스트` | 주석 |
| `/// 텍스트` | 문서 주석 — MacaDoc이 읽는 표시 |
| `//// 텍스트` | 다시 주석. 슬래시 넷은 문서 주석이 아님 |

컴파일러에게 셋은 전부 같은 토큰입니다. 세 번째 슬래시는 문서 생성기가 읽는
관례이지 키워드가 아닙니다.

## 선언

| 형태 | 선언하는 것 |
|---|---|
| `f(a: T, b: U) -> R { … }` | 블록 본문 함수 |
| `f(a: T) -> R => e` | 화살표 본문 함수 |
| `f(a) => e` | 매개변수와 결과를 추론 |
| `Name = { f: T }` | 레코드 타입 |
| `Name = A \| B(int)` | 합타입 |
| `alias N = T` | 타입의 이름 |
| `Name = e` | 상수 |
| `import a/b` | 모듈 |

함수의 반환 타입은 생략할 수 있고 본문에서 추론됩니다. 매개변수의 타입도
생략할 수 있고 사용에서 추론됩니다. 본문에서 호출되면 함수로 추론됩니다.

`alias N = T`는 `N`을 `T`의 이름으로 도입합니다. 검사기는 둘을 접어서 같게
만들지 않고 서로 다른 이름으로 다루므로, `N`이 선언된 자리에 넘기려면 값에
`N`을 표기해야 합니다. 타입에 이름을 붙이는 용도이지, 타입 사이를 오가는
용도가 아닙니다.

**레코드**는 한 줄에 `field: type` 하나씩 선언합니다. 줄 끝의 쉼표는 써도 되고
없어도 됩니다. **합타입**은 변형을 `|`로 구분하고, 변형은 매개변수 목록처럼 쓴
페이로드를 실을 수 있습니다.

```maca
Shape = Circle(int) | Rect(int, int) | Empty
```

둘 다 자기 자신을 참조할 수 있습니다. 자기 참조 합타입 페이로드는 박싱되고,
자기 참조 레코드 필드는 생성된 C에서 전방 선언됩니다.
[메모리와 소유권](a8-memory.md)을 보세요.

## 바인딩

| 형태 | 바인딩하는 것 |
|---|---|
| `x = e` | 가변 변수 |
| `const x = e` | 상수 |
| `x = e as const` | 상수 |
| `Name = e` | 대문자로 시작하므로 상수 |
| `x: T = e` | 타입을 명시 |

`let`은 없습니다. 같은 `=`가 이름을 도입하고 갱신합니다. 함수 안에서 첫
`x = e`가 선언이고 나중의 것은 대입입니다. 상수에 재대입하면 `Immutable`
진단입니다.

## 타입

| 형태 | 타입 |
|---|---|
| `int` `float` `bool` `str` | 스칼라 |
| `T[]` | `T`의 리스트 |
| `Map str V` | 문자열 키 맵. 병치로 적용 |
| `Future a` | `spawn`의 결과 |
| `a`, `b`, … | 타입 변수 — 소문자 이름이면 무엇이든 |
| `any` | 점진적 탈출구 |

타입 자리의 소문자 이름은 변수, 대문자 이름은 구체 타입입니다. 제네릭은 그게
전부입니다. 이 언어에 꺾쇠 괄호는 없습니다.

## 식

| 형태 | 의미 |
|---|---|
| `42` `3.14` `true` `"hi"` | 리터럴 |
| `0xff` `0b1010` `0o755` `1_000_000` | 정수 리터럴. `_`는 무시 |
| `[a, b, c]` | 리스트 |
| `lo..hi` | 양끝 포함 정수 범위. `int[]` |
| `Name { f = v }` | 레코드 리터럴 |
| `{ f = v }` | 필드가 타입을 정하는 레코드 리터럴 |
| `base with { f = v }` | 함수형 갱신 |
| `r.f` | 필드 |
| `xs[i]` | 리스트의 원소 또는 `str`의 한 바이트 |
| `f(a, b)` | 호출 |
| `x.f(y)` | UFCS — `f(x, y)`와 정확히 같음 |
| `Circle(2)` | 페이로드를 실은 변형 |
| `v => e` | 람다 |
| `(a, b) -> T => e` | 반환 타입을 선언한 람다 |
| `c ? x : y` | 삼항 |
| `if c { a } else { b }` | 값 자리의 조건식 |
| `match e { … }` | 값 자리의 match |
| `{ … }` | 블록. 값은 마지막 식 |
| `spawn f(x)` | 동시 실행. `Future a`를 줌 |
| `await fut` | 값이 준비되면 그 값 |
| `fail "msg"` | 발생 |
| `try e` | 잡기. 메시지 또는 `""` |
| `x?` | 호출자에게 실패 전파 |
| `tag(attr="v", child)` | 요소 — [UI 문법](a11-ui.md) 참조 |

람다 본문은 블록이 될 수 있으므로, `=>` 뒤의 맨 `{ … }`는 레코드 리터럴이
아니라 그 블록입니다. 레코드를 뜻했다면 괄호로 감싸세요: `(n) => ({ x = n })`.
match 팔의 `=> { … }`도 같은 이유로 블록입니다.

두 해석이 모두 살아 있는 곳은 **이름 있는 함수**의 `=> { … }` 하나뿐이고,
본문의 모양이 그것을 결정합니다. 레코드 리터럴의 필드는 `name = value`이고
쉼표로 구분되며, 블록의 문은 줄바꿈으로 구분되고 마지막 문이 값입니다.

```maca
// 블록: 마지막 줄이 맨 식이고, 그것은 필드가 될 수 없습니다
total() -> int => {
    a = 1
    a + 41
}

// 레코드 리터럴: 쉼표는 필드를 구분하고, 문은 결코 구분하지 않습니다
origin() -> Point => { x = 0, y = 0 }
```

블록 형태에서 화살표는 아무것도 더하지 않으므로 컴파일러는 평범한 표기를
유지합니다. `f() -> R => { … }`는 `f() -> R { … }`이며, 프리티 프린터(LSP를
통한 편집기의 포맷 명령, MCP의 `maca.fmt`)가 `=>` 없이 되돌려 씁니다. 명령줄의
`maca fmt`는 들여쓰기만 고치므로 어느 표기를 썼든 그대로 둡니다.

다음 셋은 각각 혼자서 레코드 해석을 배제합니다. 어느 것도 필드가 될 수 없기
때문입니다. `name = value`가 아닌 엔트리(맨 식, `xs[i] = v`, `p.f = v`,
`const x = e`, 축약형 `{ x, y }`), 두 번 바인딩된 이름(`x` 필드를 둘 가진
레코드는 없습니다), 그리고 빈 중괄호입니다.

모든 엔트리가 서로 다른 `name = value`이고 줄바꿈만이 그것들을 구분한다면 두
해석이 모두 성립하므로 어느 쪽도 택하지 않습니다.

```
`mk`: this `=> { … }` reads as a record literal and as a block. Write
`Name { … }` for the record, or drop the `=>` for the block
```

여기서 추측하지 않으려고 이 규칙이 있습니다. 생성자를 이름으로 쓰거나
(`Point { x = 1 }`) 화살표를 떼면 결정되고, 둘 다 어느 쪽을 뜻했는지 분명히
말합니다. 쉼표 하나도 마찬가지입니다. `{ x = 1, }`은 레코드입니다. 끝에 붙은
쉼표 역시 블록에는 없는 것이기 때문입니다.

## 문

| 형태 | 하는 일 |
|---|---|
| `x = e` | 바인딩 또는 대입 |
| `xs[i] = e` | 인덱스를 통한 대입 |
| `r.f = e` | 필드 대입 |
| `while c { … }` | `c`인 동안 반복 |
| `for x in xs { … }` | 리스트나 범위를 순회 |
| `break` `continue` | 탈출, 다음 반복으로 |

`for i in lo..hi`는 세는 루프로 낮춰지고 리스트를 만들지 않습니다. 값 자리의
범위(`xs = 1..n`)는 리스트를 만듭니다.

`break`와 `continue`에는 값이 없으므로 삼항의 갈래가 될 수 없습니다.
`c ? continue : 0`은 `TypeMismatch`입니다.

## 패턴

패턴은 `match` 갈래에 나타납니다.

| 패턴 | 매치되는 것 |
|---|---|
| `Red` | 무인자 변형 |
| `Circle(r)` | 변형. 페이로드를 `r`에 바인딩 |
| `Rect(w, h)` | 페이로드 필드가 여럿인 변형 |
| `[]` | 빈 리스트 |
| `[x]` | 정확히 하나짜리 리스트 |
| `[x, ..rest]` | 머리와 나머지 |
| `x, ..rest` | 같음. 대괄호 생략 |
| `{ x, y }` | 레코드. 필드를 바인딩 |
| `1` `"ok"` | 리터럴 |
| `_` | 무엇이든 |

합타입에 대한 `match`는 모든 변형을 다뤄야 하고, 아니면 `NonExhaustive`
진단이 따릅니다. `_`가 그것을 만족시키는데, 그래서 갈래를 쓰는 편이 낫습니다.

## 문자열

`"…"` 문자열은 보간을 하고 **줄을 넘지 못합니다**. `"""…"""` 문자열은 여러 줄에
걸치고, 보간을 하지 않으며, 이스케이프도 받지 않습니다.

| 형태 | 의미 |
|---|---|
| `{expr}` | 보간 |
| `{expr:spec}` | 포맷 스펙이 붙은 보간 |
| `\{` `\}` 또는 `{{` `}}` | 리터럴 중괄호 |
| `\n` `\t` `\r` `\0` `\\` `\"` | 이스케이프 |

포맷 스펙은 `[정렬][0][너비][.정밀도]`이고 각 부분은 모두 선택입니다.

| 스펙 | 뜻 |
|---|---|
| `>` `<` `^` | 오른쪽, 왼쪽, 가운데 정렬 |
| `0` | 공백 대신 0으로 채움 |
| `8` | 최소 너비 |
| `.3` | 소수점 자릿수 |

파서가 스펙을 직접 쓸 수도 있었을 호출로 풀어 줍니다. `{x:.2}`는
`x.fixed(2)`이고 `{x:>8}`은 `str(x).pad_start(8, " ")`이므로, 모든 타깃이
똑같이 렌더링합니다.

## 줄바꿈

줄바꿈은 의미가 있습니다. 문장을 끝냅니다. 식이 다음 줄로 이어지는 경우는
둘이고, 그 차이가 중요합니다.

**줄 끝의 연산자는 언제나 이어집니다.** 연산자를 줄 끝에 두면 다음 줄은 어떤
연산자든 같은 식의 일부입니다.

```maca
total = base +
    extra
```

**줄 앞의 토큰은 그것이 식을 시작할 수 없을 때만 이어집니다.** `&&`, `||`,
`++`, `.`, `?`, `:`가 여기 해당하므로 아래는 각각 하나의 식입니다.

```maca
ok = a > 0
    && b > 0

name = first
    ++ " "
    ++ last

n = text.split(",")
    .length()

label = score >= 60
    ? "pass"
    : "fail"
```

그 밖의 것이 줄 앞에 오면 새 문장입니다. `+`, `*`, `/`, `%`, `<<`, `>>`와 비교
연산자에게 그것은 파싱 에러이고, 이쪽이 좋은 경우입니다.

```
parse (58, 59): unexpected token Plus
```

`-`와 `!`에게는 에러가 **아닙니다**. 둘 다 식을 시작할 수 있기 때문입니다. 줄
앞의 `-`는 새 문장을 시작하고, 위의 바인딩은 원래 값을 그대로 지닙니다.

```maca
n = a
    - 3        // n은 a. `- 3`은 그 자체로 문장
```

이 경우에는 아무 경고도 없습니다. 연산자를 줄 끝에 두거나, 중간 지역 변수에
이름을 붙이세요.

## 대괄호 없는 리스트

모양이 모호하지 않은 곳에서는 콤마 리스트에 대괄호가 필요 없습니다. 리스트를
돌려주는 화살표 본문, `for` 헤더, 나머지 패턴이 그렇습니다.

```maca
pair() -> int[] => 1, 2
```

호출 인자는 쉼표로 나눠도 되고 **아무것도 쓰지 않아도** 됩니다. 뒤쪽이 중첩된
마크업을 읽기 좋게 만들어 주는 쪽이고, 요소의 자식 사이에 구두점이 필요 없는
이유입니다.

```maca
article(class="prose",
    h1("Title")
    span("Body"))
```
