# Maca로 Maca 만들기

자기 자신을 컴파일하지 못하는 언어는, 만든 사람들보다 더 그 언어를 믿어 달라고
요구하는 셈입니다. Maca는 부트스트랩 중이고, 이 장은 그 모양을 설명합니다. 일부는
흥미롭기 때문이고, 대부분은 새 컴파일러 작업이 가야 할 곳이기 때문입니다.

## 두 단계

**스테이지 0**은 `crates/` 아래의 Rust 컴파일러입니다. 부트스트랩이고,
동결되어 있습니다. 진짜 부트스트랩 버그 — 멈추는 파서, 잘못 파싱되는 구문 —
때문에만 바뀝니다. 기능을 추가하는 곳이 아닙니다.

**스테이지 1**은 `selfhost/` 아래의 Maca 컴파일러입니다. Maca로 쓰였습니다.
새 컴파일러 작업이 속하는 곳입니다. 스테이지 0이 이것을 컴파일하고, 테스트
게이트(`crates/driver/tests/selfhost.rs`)가 계속 동작하는지 확인합니다.

규칙은 짧습니다. Rust 크레이트를 키우는 것보다 `selfhost/*.maca`에 추가하는
쪽을 택하세요.

## 스테이지 1이 지금 하는 일

프론트엔드 전체가 네이티브로 돕니다.

```
lexer.maca → parser.maca → ast.maca → check.maca → emit_c.maca
                                                 → emit_rust.maca
```

손으로 쓴 렉서, 재귀 `Expr` AST와 pretty-printer를 만드는 재귀 하향 파서, 거친
타입 검사기, 그리고 백엔드 **둘** — 하나는 C를, 하나는 Rust를 내보냅니다.

다루는 Maca의 범위는 장난감을 훨씬 지났습니다. 원시 식 언어 전체(정수, 실수,
문자열, 불리언 리터럴, 산술, 비교, `&&`/`||`, 단항 `-`/`!`, 삼항, 올바른
우선순위의 다중 인자 및 중첩 호출), 선언된 타입이 C의 `const char*`/`double`/
`bool`과 Rust의 `String`/`f64`로 흘러가는 타입 배선된 시그니처, 레코드, 그리고
`match`가 붙은 무인자 합타입입니다.

## 게이트가 동작하는 방식

부트스트랩을 하게 된다면 베껴갈 만한 부분입니다.

이 테스트는 스테이지 1 컴파일러가 *기대한* 출력을 내는지 확인하지 않습니다.
그 출력이 **동작하는지**를 확인합니다.

1. 스테이지 0이 호스트 `cc`로 스테이지 1 컴파일러를 네이티브 바이너리로 빌드합니다.
2. 그 바이너리가 Maca 프로그램 하나를 두 번 처리합니다. 한 번은 C를, 한 번은
   Rust를 내보내면서요.
3. 내보낸 C를 `cc`로 컴파일해 실행합니다. 내보낸 Rust를 `rustc`로 컴파일해
   실행합니다.
4. 둘 다 `self-hosted!`를 출력하고 `42`로 종료해야 합니다.

골든 출력 테스트라면 코드 생성기의 공백이 바뀔 때마다 깨집니다. 이 테스트는
컴파일러가 실제로 틀렸을 때만 깨지고, 같은 소스에 대해 두 백엔드를 모두
검증하므로 "C 경로는 되는데 Rust 경로가 조용히 안 되는" 종류의 버그를 통째로
잡습니다.

## 이것을 가능하게 한 두 기능

컴파일러를 돌리려면 언어에서 두 가지가 필요했는데, 둘 다 컴파일러 전용이 아니라
일반적으로 유용한 것으로 드러났습니다.

**문자열 스캐닝.** `chars`, `length`, `at`, `get`, `slice`, 그리고 문자 분류
`is_whitespace`, `is_ascii_digit`, `is_alpha`. `selfhost/lexer.maca`가 쓰는
어휘의 전부입니다. 어떤 토크나이저든 정확히 이 집합을 필요로 합니다.

**재귀 레코드 타입.** AST 노드가 AST 노드의 리스트를 담습니다.

```maca
Expr = {
    kind: int
    text: str
    children: Expr[]
}
```

C에서 이것은 정의 순환입니다. 배열 타입은 구조체의 크기를, 구조체는 배열을
필요로 하니까요. 백엔드는 레코드 본문 앞에 배열 구조체를 전방 선언하고 연산은
뒤에 내보내어 순환을 끊습니다. 5장에서도 언급했는데, 셀프호스팅 AST가 필요로
했기 때문에 존재하는 기능입니다.

## 소스 읽기

`selfhost/main.maca`가 진입점이고, 테스트 스위트 역할도 겸합니다. 일련의
프로그램을 렉싱, 파싱, 검사, 코드 생성하고 각각을 보고합니다. 현재 상태를 보는
가장 빠른 방법입니다.

```
maca run selfhost/main.maca
```

파일들은 작고 일부러 평범합니다. `lexer.maca`는 문자 스캐너입니다.
`parser.maca`는 우선순위 표가 붙은 재귀 하향입니다. `emit_c.maca`는 문자열
템플릿입니다. 해독할 영리함이 없는데, 그게 의도입니다. 읽기 어려운 부트스트랩
컴파일러는 아무도 끝내지 못할 부트스트랩 컴파일러입니다.

## 남은 것

타입 검사기가 거칩니다. 스테이지 1에는 모듈 시스템도, 클로저도, 제네릭도,
이펙트도 없습니다. 그것이 스테이지 1과 스테이지 0 사이의 간극이고, 그것을
메우는 것이 남은 일입니다.

방향은 스테이지 0을 한 줄씩 포팅하는 것이 아닙니다. 각 조각을 Maca로 쓰고,
컴파일-실행 캡스톤으로 게이트를 걸고, 두 구현이 어긋나면 시끄럽게 어긋나도록
두는 것입니다.
