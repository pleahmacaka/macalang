# 첫 프로그램

언어를 익히는 가장 좋은 방법은 그 언어로 작은 것을 만들어 보는 것입니다. 이
장에서는 프로그램 하나를 처음부터 끝까지 만듭니다. 문장을 받아 각 단어가 몇 번
나왔는지 세는 단어 집계기입니다. 레코드, 리스트, 재귀, 문자열 처리를 두루
건드리는데, 이후 장에서 자세히 다룰 것들이라 여기서는 전부 설명하지 않습니다.
전체적인 모양만 보시면 됩니다.

완성된 프로그램은 저장소의 `examples/wordcount.maca`에 있고, 테스트 스위트가
이를 실행합니다. 그러니 아래 내용은 실제로 동작하는 것이 확인된 것입니다.

## 문장 쪼개기

입력과 가장 작은 유용한 단계부터 시작합니다. 문장을 단어로 만드는 일입니다.

```maca
words(text: str) -> str[] =>
    text.lower().replace(".", " ").replace(",", " ").split(" ")
```

눈여겨볼 것이 셋 있습니다.

`str[]`는 문자열의 리스트입니다. Maca는 원소 타입을 먼저 쓰고 대괄호를 뒤에
붙입니다. C처럼요. `List<str>`이 아닙니다. 이 언어에는 꺾쇠 괄호가 아예
없습니다.

`text.lower()`는 문자열에 대한 메서드 호출처럼 보이지만, `str`는 자기 메서드를
가지지 않는 기본 타입입니다. 이것이 **UFCS**(uniform function call syntax)입니다.
`x.f(y)`는 `f(x, y)`를 뜻하므로, 첫 인자 타입만 맞으면 어떤 함수든 이렇게 부를
수 있습니다. 덕분에 체인이 일이 일어나는 순서대로 왼쪽에서 오른쪽으로 읽힙니다.

본문은 **화살표 본문**입니다. `=>` 다음에 식 하나가 오고, 그것이 함수의
결과입니다. Maca에는 `return`이 없습니다.

## 세기

단어와 그 횟수는 같이 다니므로, 이름을 붙여 줍니다.

```maca
Tally = {
    word: str
    count: int
}
```

이것이 레코드, Maca의 구조체입니다. `Name = { … }`로 타입을 선언하고, 안에
`field: type`을 씁니다. 문장부호의 두 가지 의미를 눈여겨보세요. 언어 전체에서
일관됩니다. **`:`는 타입을 도입하고, `=`는 값을 도입합니다.**

이제 실제 일을 하는 연산입니다. 단어 하나를 목격했다고 기록합니다.

```maca
bump(ts: Tally[], w: str) -> Tally[] {
    at = find(ts, w, 0)
    at < 0
        ? ts ++ [Tally { word = w, count = 1 }]
        : replace_at(ts, at, Tally { word = w, count = ts.get(at).count + 1 })
}
```

이 함수는 **블록 본문**입니다. `=>` 대신 중괄호를 쓴 이유는 지역 바인딩이 먼저
필요하기 때문입니다. 블록의 마지막 식이 여전히 값입니다. 역시 `return`은
없습니다.

`at = find(...)`이 지역 변수를 바인딩합니다. `let`은 없습니다. `c ? a : b`가
삼항 연산자이고, 이것은 식이므로 함수 본문 전체가 될 수 있습니다.

`++`는 이어붙입니다. 여기서는 리스트를, 다른 곳에서는 문자열을요.

`Tally { word = w, count = 1 }`이 레코드를 만듭니다. 타입 이름 다음에
`field = value` 쌍이 옵니다. 값이니까 `=`입니다.

도우미 두 개입니다.

```maca
find(ts: Tally[], w: str, i: int) -> int =>
    i >= ts.length() ? -1 : (ts.get(i).word == w ? i : find(ts, w, i + 1))

replace_at(ts: Tally[], at: int, t: Tally) -> Tally[] {
    ts[at] = t
    ts
}
```

`find`는 재귀 함수이고, 커서 `i`를 매개변수로 직접 들고 다닙니다. Maca 코드에서
계속 보게 될 모양입니다. 컴파일러 자신도 이렇게 쓰여 있습니다.

`replace_at`은 반대쪽을 보여줍니다. `ts[at] = t`는 인덱스를 통해 대입합니다.
Maca는 순수 함수형 언어가 아닙니다. 다만 식을 선호할 뿐입니다.

## 단어들을 접기

```maca
tally(ws: str[], i: int, acc: Tally[]) -> Tally[] =>
    i >= ws.length()
        ? acc
        : tally(ws, i + 1, ws.get(i).length() == 0 ? acc : bump(acc, ws.get(i)))
```

재귀 호출을 통해 누산기를 넘기는, 표준적인 fold입니다. 공백으로 나누면 빈
문자열이 남으므로(`"a.  b"`가 하나 만듭니다) 빈 단어는 세지 않고 건너뜁니다.

## 출력

```maca
show(ts: Tally[], i: int) -> int {
    if i < ts.length() {
        info("{ts.get(i).word:<8} {ts.get(i).count}")
        show(ts, i + 1)
    }
    0
}
```

`info`가 한 줄을 출력합니다. 문자열은 **보간**됩니다. `{식}`이 평가되어 그
자리에 들어갑니다. `{…:<8}`은 포맷 스펙으로, 8칸에 왼쪽 정렬하라는 뜻입니다.
그래서 숫자가 세로로 맞습니다. 스펙 문법 전체는
[다음 장](03-common-concepts.md)에서 다룹니다.

여기서 `if`는 값이 버려지는 문장이고, 블록의 값은 마지막 줄의 `0`입니다.

## main

```maca
main() -> int {
    text = "the quick brown fox. the lazy dog, the end."
    ts = tally(words(text), 0, [])
    info("{ts.length()} distinct words")
    show(ts, 0)
    0
}
```

`main() -> int`가 진입점이고, 그 결과가 프로세스 종료 상태입니다. 다른 모든
곳과 마찬가지로 `0`이 성공입니다.

## 실행하기

```
maca run examples/wordcount.maca
```

```
7 distinct words
the      3
quick    1
brown    1
fox      1
lazy     1
dog      1
end      1
```

`maca run`은 컴파일과 실행을 한 번에 합니다. 그 뒤에서는 프로그램이 파싱되고,
타입 검사를 받고, C로 낮춰지고, 진짜 C 컴파일러가 컴파일하고, 결과 바이너리가
캐시됩니다. 바뀌지 않은 프로그램을 다시 실행하면 이 전부를 건너뜁니다.

## 설명하지 않은 것

일부러 남긴 것들입니다. 왜 `Tally`가 클래스가 아니라 레코드인지, 리스트를 다시
만들 때 메모리에 무슨 일이 일어나는지, 왜 `return`이 없는지, `str[]`이 메서드를
어디서 얻는지. 다음 장들의 내용입니다. 여기서 중요한 것은 프로그램이 함수들의
목록이고, 함수가 시그니처와 식 하나이며, 언어가 길을 비켜준다는 점입니다.
