# 레코드

레코드는 이름 붙은 필드들을 하나의 타입 이름 아래 묶는, Maca의 구조체입니다.

## 선언과 생성

```maca
Point = {
    x: int
    y: int
}
```

선언은 `Name = { … }`입니다. 안에는 한 줄에 `field: type` 하나씩 쓰고, 줄 끝
쉼표는 있어도 없어도 됩니다.

값을 만들 때는 `:`가 아니라 `=`를 씁니다.

```maca
p = Point { x = 3, y = 4 }
```

**`:`는 그것이 무엇인지를 말하고, `=`는 그것이 무엇을 담는지를 말합니다.**
레코드 선언, 레코드 리터럴, 함수 매개변수, 바인딩 모두에서 일관됩니다.

필드는 점으로 읽습니다.

```maca
info("{p.x}, {p.y}")
```

## 갱신

레코드는 값이므로, 바뀐 것을 얻으려면 `with`를 씁니다.

```maca
q = p with { y = 5 }
```

`q`는 `x = 3, y = 5`인 `Point`이고, `p`는 그대로입니다. 여러 필드를 한 번에
바꿀 수 있고, 언급하지 않은 필드는 그대로 넘어옵니다.

```maca
r = p with { x = 0, y = 0 }
```

이것이 반드시 복사인 것은 아닙니다. 아무도 `p`를 붙들고 있지 않을 때 컴파일러는
`with`를 이미 있던 메모리에 대한 저장으로 만듭니다. [메모리](04-memory.md)가
이유를 설명합니다.

만들어 나가는 중인 지역 레코드를 위한 직접 필드 대입도 있습니다.

```maca
p.x = 10
```

## 시그니처 속의 레코드

레코드 타입은 다른 타입과 똑같이 쓰입니다.

```maca
Rect = {
    w: int
    h: int
}

area(r: Rect) -> int =>
    r.w * r.h

scale(r: Rect, k: int) -> Rect =>
    r with { w = r.w * k, h = r.h * k }
```

UFCS(`x.f(y)`는 `f(x, y)`) 덕분에 메서드로 선언한 적이 없는데도 호출 지점에서는
메서드처럼 읽힙니다.

```maca
big = Rect { w = 2, h = 3 }.scale(10)
info("area: {big.area()}")
```

`impl` 블록도 `self`도 없고, "메서드"와 "첫 인자가 Rect인 함수" 사이의 구분도
없습니다.

## 레코드를 담은 레코드

필드는 다른 레코드나 그 리스트도 될 수 있습니다.

```maca
Line = {
    from: Point
    to: Point
}

Shape = {
    name: str
    points: Point[]
}
```

접근은 중첩됩니다. `l.from.x`.

레코드는 **자기 자신**을 참조할 수도 있습니다. 트리를 만드는 방법입니다.

```maca
Node = {
    label: str
    children: Node[]
}
```

C에서 자기 자신의 배열을 담은 구조체는 정의 순환입니다. Maca의 C 백엔드는 레코드
본문 앞에 배열 구조체를 전방 선언하고 연산은 뒤에 내보내어 순환을 끊습니다.
자기 참조 레코드는 우연이 아니라 지원되는 기능입니다.

## 이름 없는 레코드

앞에 타입 이름이 없는 레코드 리터럴은 존재하는 필드에서 타입을 추론합니다.

```maca
c = { host = "localhost", port = 8080 }
info("{c.host}:{c.port}")
```

같은 필드를 가진 두 리터럴은 쓴 순서와 무관하게 같은 타입이라 서로 대입할 수
있습니다.

```maca
d = { port = 80, host = "example.com" }
c = d                                    // 같은 모양이라 괜찮습니다
```

한 곳에서 한 번만 쓰이는 모양일 때 쓰세요. 같은 모양이 두 번을 넘게 나오면
이름을 붙이세요. 진단 메시지가 이야기할 수 있는 것은 이름입니다.

## 실행해 보기

```
maca run apps/examples/record_update.maca
```

레코드에 `with`를 쓰고 원본이 그대로인지 확인합니다. 아무도 그 값을 붙들고
있지 않으면 갱신은 같은 메모리에 쓰는 저장이 되고, 누군가 붙들고 있으면 복사가
됩니다. 프로그램은 그 차이를 알 수 없습니다.

## 레코드 대 합타입

레코드는 "이것들 전부 동시에"를 말합니다. "이것들 중 하나"가 필요하다면 그것은
합타입입니다.
