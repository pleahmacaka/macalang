# 소개

**Maca 핸드북**은 Maca를 가르치고, 그다음에는 레퍼런스가 됩니다.

Maca는 **프로그램과 인프라 설정을 모두** 다루는 하나의 정적 타입 언어입니다.

## Maca가 다른 점

**하나의 언어, 여러 타깃.** Maca는 유니버설 트랜스파일러입니다. 기계어를
내지 않고 다른 언어를 씁니다: 프로그램은 C, JavaScript, Java, Rust, Elixir,
마이크로컨트롤러용 freestanding C로 번역되고, 바이너리와 페이지는 그 언어의
도구가 만듭니다. 어느 쪽이 나오는지는 플래그가 정합니다.

**GC도 없고 borrow checker도 없습니다.** 메모리는 참조 카운팅으로 관리되고 그
대부분을 컴파일러가 걷어냅니다. 라이프타임도 `clone()`도 없습니다.

**`async` 키워드가 없습니다.** `spawn f(x)`가 `f`를 동시에 실행하고 `await`이
기다립니다. 이 둘을 쓴 함수는 시그니처를 바꾸지 않은 채 비동기가 됩니다.

**설정도 코드이고, 코드처럼 검사됩니다.** Maca로 쓴 인프라는 Nix로 컴파일되기
전에 타입 검사를 받습니다.

## 이 책의 대상

코드를 짜본 적이 있다면 충분합니다.

## 이 핸드북은 책 두 권입니다

**Maca 배우기**는 가르치는 책이고 모든 장이 직접 실행해 볼 것으로 끝납니다.
**레퍼런스**는 답하는 책입니다. 이펙트 행, 소유권 규칙, import 해결 순서,
백엔드별 차이, 진단 메시지 전체 목록이 여기 있습니다.

## Maca 배우기를 읽는 방법

앞에서 뒤로. 각 장은 앞 장 위에 쌓입니다.

- **시작하기**: 컴파일러를 설치하고 프로그램 두 개를 씁니다.
- **언어**: 값, 레코드, 합타입, 컬렉션, 에러, 함수, 모듈, 메모리, 테스트.
- **Maca가 다르게 하는 것**: 컬러블라인드 async, config 모드, UI 문법, 타깃.
- **만들어 보기**: 진짜 도구 하나를 처음부터 끝까지 만듭니다.

이미 언어를 안다면 [문법](a5-syntax.md)부터 시작하세요.

## 여기 있는 것은 전부 실행해 봤습니다

`apps/examples/handbook.maca`가 이 책의 주장들을 하나의 프로그램에 담아 테스트
스위트가 실행합니다. 키워드 목록은 렉서와, 진단 목록은 검사기와, 메서드 표는 그
안의 모든 이름을 호출하는 프로그램과 대조합니다.

[설치부터 시작합니다.](01-installing.md)
