# 인터페이스와 문서

Maca에는 HTML 요소를 위한 문법과, 여러분이 쓴 클래스를 읽어 스타일시트를
만들어 주는 생성기가 있습니다. 둘 다 라이브러리가 아니라 언어의 일부이고, 둘 다
하나의 타깃에만 묶여 있지 않습니다. 같은 마크업이 브라우저에서는 살아 있는
DOM이 되고, 네이티브 바이너리에서는 HTML 문자열이 됩니다.

지금 읽고 계신 이 페이지도 그렇게 만들어졌습니다.

## 요소는 호출이다

HTML 태그 이름은 그대로 호출할 수 있습니다.

```maca
article(class="prose",
    h1("안녕하세요")
    span("본문"))
```

이름 있는 인자는 속성이 되고, 위치 인자는 자식이 됩니다. 자식은 쉼표로 나눠도
되고 아무것도 쓰지 않아도 됩니다. 뒤쪽이 중첩된 마크업을 읽기 좋게 만들어 주는
쪽이고, 위 예제에서 제목과 문단 사이에 아무 구두점이 없는 이유입니다.

빠뜨릴 닫는 태그도, 템플릿 언어도, 별도 파일도 없습니다. 요소는 평범한
표현식이므로 나머지 모든 것과 어울립니다. 함수 안에서 만들 수도, 리스트에 담을
수도, `match`에서 반환할 수도 있습니다.

```maca
item(name: str) -> str => li(name)

list_of(names: str[]) -> str =>
    ul(names.map(item).join(""))
```

## 타깃은 둘, 문법은 하나

```
maca build app.maca --target js -o out
```

는 반응형 페이지를 만듭니다. 요소는 `createElement` 호출이 되고, `onclick=`
은 핸들러를 붙이며, 상태 이름에 붙은 `value=` 는 그 이름을 양방향으로 묶습니다.
이름은 플랫폼의 것 그대로라, `oninput=`, `ondragstart=`, `ondrop=` 모두 HTML
에서 쓰던 철자 그대로 씁니다.

```maca
count = 0

bump() { count = count + 1 }

main() -> Element =>
    div(
        button(onclick=bump, "+")
        span("{count}")
    )
```

이 프로그램에는 다시 그리라는 호출이 없고, 있어야 할 이유도 없습니다.
**선언된 이름에 대입하는 것이 곧 갱신입니다.** `count = count + 1` 은 `count`
가 바뀌었다고 표시하고, `count` 를 읽는 노드가 다시 실행됩니다. 한 핸들러가
이름 셋에 대입해도 다시 그리는 것은 핸들러가 끝날 때 한 번이고, 같은 이름에
백 번 대입하는 루프도 루프가 끝난 뒤 한 번입니다.

`update()` 는 그대로 남아 있습니다. Maca 바깥에서 무언가 움직여 뷰가 알 길이
없는 경우를 위해서입니다. `import js` 블록이 대화하는 브리지의
`maca.refresh()` 가 바로 그것입니다.

```
maca build gen.maca -o gen
```

는 네이티브 바이너리를 만들고, 거기서 같은 요소는 **텍스트**로 렌더링됩니다.

```maca
main() -> int {
    info(article(class="prose", h1("Hi") span("Body")))
    0
}
```

```
<article class="prose"><h1>Hi</h1><span>Body</span></article>
```

정적 사이트 생성기에 필요한 것이 정확히 이것입니다. 문자열에는 이벤트 핸들러가
붙을 자리가 없으므로, 네이티브 타깃에서 예전 철자인 `on:click=` 지시자는 컴파일
오류가 되어 `js` 로 빌드하라고 알려 줍니다. 조용히 아무 일도 하지 않는 마크업을
내놓는 대신에요. 반면 평범한 `onclick="…"` 은 거기서 보통의 HTML 속성입니다.
HTML 자신이 그렇게 읽으니까요.

## 정의가 태그를 이긴다

`label`, `code`, `main`, `section`, `p`, `a`, `form`, `option` 은 HTML 태그
*이면서* 사람들이 자기 함수에 붙이는 이름이기도 합니다. 그 이름이 정의되어
있으면 정의가 이깁니다.

```maca
label(pos: bool) -> str => pos ? "오른쪽" : "왼쪽"

main() -> int {
    info(label(true))     // "오른쪽": <label>이 아니라 여러분의 함수
    info(span("tag"))     // "<span>tag</span>": `span`을 가리는 것은 없음
    0
}
```

이것은 특정 이름 목록을 위한 예외가 아니라, 태그를 따지기 전에 적용되는 평범한
스코프 규칙입니다.

## 뷰는 요소 목록을 낼 수 있다

자식은 보통 요소 하나입니다. **목록**이어도 되고, 그러면 목록의 각 원소가 그
자리의 자식이 됩니다.

```maca
Link = { title: str, icon: str }

pencil(on: bool) -> Element[] {
    if !on {
        return []
    }

    [button(class="pencil", "edit")]
}

row(link: Link, on: bool) -> Element =>
    li(class="row",
       [i(class="icon", link.icon), span(class="title", link.title)]
           ++ pencil(on))
```

`Element`는 렌더링된 요소의 타입이고 `Element[]`는 그 목록입니다. `[]`는
**아무것도 내지 않습니다.** JS 타깃에서는 노드가 없고, 네이티브에서는 마크업이
없습니다. 이것이 핵심입니다. 보여줄 것이 없는 뷰는 브라우저가 어쨌든 만들고
배치해야 하는 `class="hidden"` 요소 대신 빈 목록을 돌려줍니다.

`++`는 두 요소 목록을 잇고, `.map`은 목록을 만들며, 리스트 리터럴은 적어 놓은
목록입니다. 넷 모두 부모에게 같은 방식으로 도착합니다.

```maca
ul(links.map(l => row(l, editing)))
```

함수는 시그니처로 그렇게 말해야 합니다. `-> Element`나 `-> Element[]`가
이 호출이 텍스트가 아니라 노드를 돌려준다고 컴파일러에 알려 줍니다. `str`을
돌려주는 함수는 여전히 텍스트로 렌더링되는 자식이고, `"{n} items"`에는 그쪽이
맞습니다.

## 스타일은 링크하는 것이 아니라 생성되는 것

클래스는 Tailwind의 유틸리티 이름으로 `class=` 에 쓰고, 컴파일러는 프로그램이
실제로 언급한 유틸리티에 대한 스타일시트를 만들어 냅니다. `styles()` 가 그것을
문자열로 돌려줍니다.

```maca
page() -> str =>
    div(class="max-w-2xl mx-auto font-bold", "텍스트")
```

```css
.font-bold { font-weight:700; }
.max-w-2xl { max-width:42rem; }
.mx-auto { margin-left:auto;margin-right:auto; }
```

쓰인 유틸리티 하나당 규칙 하나입니다. 프로그램이 언급하지 않은 유틸리티는
규칙을 만들지 않습니다. 흔들어 떨어뜨릴 프레임워크가 없는데, 애초에 아무것도
포함하지 않았기 때문입니다. 네트워크 요청도 없고, 그래서 이렇게 만든 책은
디스크에서 바로 열어도 제대로 보입니다.

## 하나 써 보기

다른 파일 없이, 페이지 하나를 온전히 만들어 봅시다.

```maca
main() -> int {
    write_file("index.html",
        "<!doctype html>\n"
        ++ html(lang="ko",
            head(
                meta(charset="utf-8")
                meta(name="viewport", content="width=device-width,initial-scale=1")
                title("메모")
                style(styles()))
            body(class="font-serif bg-white dark:bg-zinc-900",
                element("main",
                    h1(class="text-[2rem] font-bold", "메모")
                    span(class="my-4", "Maca로 썼습니다.")))))
    0
}
```

`maca run` 한 번이면 스타일이 입혀지고, 자체 완결적이며, 다크 모드를 아는
페이지가 나옵니다.

## 전체 규칙은 어디에

레퍼런스의 [UI 문법](a11-ui.md)에 나머지가 있고, 날카로운 모서리는 전부
거기에 있습니다. 하이픈이 든 속성과 그것을 가능하게 하는 붙여쓰기/띄어쓰기
규칙, 속성의 *존재 여부*를 결정하는 불리언 속성, 실행 시점에 태그를 고르는
`element(tag, …)`, 변형 표 전체(`hover:`, `dark:`, `max-md:` 와 이들의 조합),
대괄호 안의 임의 값, 그리고 클래스가 수집되지 **않는** 유일한 곳(원시
`"""…"""` 문자열 안, 끝내 만들어지지 않는 규칙을 가리키게 되는 자리).
