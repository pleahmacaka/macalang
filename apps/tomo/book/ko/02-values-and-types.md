# 값과 타입

Maca는 정적 타입 언어지만, 타입을 직접 쓰는 곳은 함수 경계 정도이고 나머지는
컴파일러가 추론합니다.

## 스칼라

- `int` — 64비트 정수: `42`, `-7`, `0xff`, `1_000_000`.
- `float` — 64비트 실수: `3.14`, `2.0`.
- `bool` — `true` 또는 `false`.
- `str` — 문자열: `"hello"`, 보간 지원: `"n = {n}"`.

## 바인딩: 가변 vs 상수

소문자 이름은 **가변** 변수를 바인딩합니다:

```
count = 0
count = count + 1   // OK
```

`const`, `as const`, 또는 **대문자로 시작하는** 이름은 **상수**를 바인딩합니다.
재할당하면 컴파일 에러입니다:

```
const Limit = 100
Limit = 200         // 에러: 상수를 재할당할 수 없음
```

`let`은 없습니다. 이름을 도입하는 것과 갱신하는 것 모두 같은 `=`를 씁니다.

## 레코드

레코드는 이름 붙은 필드를 묶습니다. 타입 선언과 값 생성:

```
Point = {
    x: int
    y: int
}

p = Point { x = 3, y = 4 }
info("x는 {p.x}")            // `.`로 필드 접근
q = p with { y = 5 }         // 함수형 갱신 — p는 그대로
```

## 합타입

합타입은 여러 variant 중 하나입니다. `match`가 이를 분해합니다:

```
Shape = Circle | Square | Triangle

sides(s: Shape) -> int =>
    match s {
        Circle   => 0
        Square   => 4
        Triangle => 3
    }
```

값은 반드시 정확히 하나의 variant이므로 `match`는 빠짐없이 다뤄야 합니다 —
variant를 빠뜨리면 컴파일러가 알려줍니다.

## 리스트

리스트는 한 타입의 값을 여럿 담습니다. stdlib 메서드는 UFCS라서 `.`로
호출합니다:

```
xs = [10, 20, 30]
info("첫값 {xs.first()}, 길이 {xs.length()}")
doubled = xs.map(n => n * 2)          // [20, 40, 60]
big     = xs.filter(n => n > 15)      // [20, 30]
total   = xs.reduce(0, (a, b) => a + b)
```

## 타입 주석은 추론 힌트

함수의 파라미터와 반환에는 주석을 답니다. 본문 안에서는 타입이 알아서
흐릅니다. Maca가 알 수 없는 것 — 알 수 없는 stdlib 값, 외부 호출 — 을 만나면
프로그램을 거부하는 대신 점진적 `any`로 물러섭니다. 덕분에 상호운용은 매끄럽게,
내 코드는 엄격하게 유지됩니다.
